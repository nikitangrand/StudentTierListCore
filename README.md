# StudentTierListCore

Приложение для ранжирования студентов по категориям (tier list) на C++.

## Стек

- C++
- ООП (классы, наследование, полиморфизм)
- Работа с коллекциями и алгоритмами

## Функциональность

- Создание списка студентов с параметрами (имя, успеваемость и т.п.)
- Автоматическое распределение по категориям (S, A, B, C, D)
- Вывод итоговой таблицы рангов

## Запуск

```bash
git clone https://github.com/nikitangrand/StudentTierListCore
cd StudentTierListCore
g++ -std=c++17 main.cpp -o tierlist
./tierlist
